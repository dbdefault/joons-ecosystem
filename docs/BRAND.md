# Brand

## Names

Write JOONS in uppercase. Use the complete product names on first mention: JOONS CORE, JOONS Agent Guard, JOONS Allocator, JOONS MCP Toolkit and JOONS MCP Probe. English is the primary documentation language; Korean documentation mirrors it. Use an emoji-free, text-first style.

Slogan: MCP-Based AI Infrastructure Ecosystem

Official description: JOONS is an MCP-centered AI infrastructure ecosystem that connects AI agents with tools, computers, knowledge, and reliable execution systems.

## Colours and status labels

| Purpose | Colour | Meaning |
|---|---|---|
| Accent | `#4F46E5` | Indigo accent for badges and diagrams |
| Public | `brightgreen` | Public product |
| Preview | `orange` | Preview release |
| Private | `lightgrey` | Private product |
| Planned | `blue` | Planned work |

Status labels describe availability, not a guarantee of integration. CORE is private and in operation; Guard and Allocator are public v0.1.0 previews; Toolkit is an early public reference implementation; Probe is Public, v0.1.0 Preview.
